Free desktop app · Windows and macOS

Blood Connect

Connects people who need blood with registered donors of the same blood group — and keeps every donor's phone number private until they accept.

Download for Windows Download for macOS

Heads up. These buttons serve the latest GitHub release. If one returns a 404, no build has been published yet — run it from source below in the meantime.

Runs entirely on your own computer. No account, no sign-up, no data leaves your machine.

What it does

  • Register as a seeker or a donor. Donors add their blood group and last donation date; passwords are stored only as salted PBKDF2 hashes.
  • Submit a request. Patient, blood group, units, hospital, city, contact and urgency.
  • Every matching donor is notified. Only donors who are available and currently eligible (90 days since their last donation) are included.
  • Donors accept or decline. Accepting marks the request "Donor found" and reveals the donor's contact number to the seeker.
  • Search registered donors by blood group and city. Numbers stay hidden until a donor agrees.

Installing

Windows: run BloodConnect.exe. If SmartScreen shows a warning, choose More info and then Run anyway — the build is unsigned.

macOS: unzip and drag BloodConnect.app into Applications. The first time, right-click the app and choose Open to get past Gatekeeper.

Accounts and requests live in one file, blood_connect.db, in your per-user application data folder. Keep it to keep your data, delete it to start over, and never share it — it holds names, phone numbers and password hashes.

Run it from source

Needs Python 3.10+ with Tkinter and no third-party packages. Clone the repository and run python run.py.

Please read

Blood Connect only introduces people to each other. Final donor eligibility and blood compatibility must always be confirmed by qualified medical staff.
